# Tarea de hoy

Copiar este archivo sobre `tareas/HOY.md` y reemplazar los campos. `HOY.md` es el único encargo que el agente ejecuta. Esta plantilla no se edita con el trabajo del día.

Para un agente en la nube, `HOY.md` tiene que estar en el repositorio que ese agente clona.

```
estado: sin-llenar
fecha:
donde: local
```

`estado`: `sin-llenar` o `lista`. `donde`: `local` o `nube`.

## Objetivo

Una frase: qué debe existir al terminar.
